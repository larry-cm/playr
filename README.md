# Plataforma de Perfiles de Streaming

Una plataforma todo-en-uno para gestionar, comprar y dar soporte a perfiles de streaming.

## ¿Qué hace esta plataforma?

Esta aplicación centraliza la administración de perfiles de usuarios que han adquirido plataformas de streaming. Desde un solo lugar puedes:

* **Gestionar perfiles** — Administra los perfiles de streaming de tus usuarios: altas, bajas, modificaciones y control de acceso.

* **Vender perfiles** — Módulo de compra integrado para que los usuarios adquieran nuevos perfiles de distintas plataformas de streaming.

* **Atender soporte** — Área de soporte técnico y atención al cliente incorporada, sin necesidad de herramientas externas.

Todo funciona dentro de una misma entidad: administración, venta y soporte conviven en una única plataforma unificada.

## ¿Para quién es?

* **Vendedores de perfiles de streaming** que necesitan una herramienta para organizar su inventario y clientes.

* **Equipos de soporte** que requieren atender incidencias sin salir del sistema.

* **Administradores** que buscan visibilidad total sobre perfiles activos, ventas y tickets de soporte.

## Tecnología

Desarrollado con [Next.js](https://nextjs.org) y desplegable en [Vercel](https://vercel.com).
